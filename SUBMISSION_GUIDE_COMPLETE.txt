How to create GitHub repository:
---------------------------------

Step 1: Create repository on GitHub
  1. Go to github.com (create account if needed)
  2. Click "+" → "New repository"
  3. Name: cd63-r9-md-analysis
  4. Description: "MD simulation analysis of CD63 vs CD9 for R9-exosome engineering"
  5. Public repository
  6. Click "Create repository"

Step 2: Upload files
  Option A - Via web interface (easiest):
    1. Click "uploading an existing file"
    2. Drag and drop all your files
    3. Organize into folders (scripts/, docs/)
    4. Commit changes

  Option B - Via command line (if familiar with Git):
    ```bash
    cd /path/to/your/code
    git init
    git add .
    git commit -m "Initial commit"
    git remote add origin https://github.com/yourusername/cd63-r9-md-analysis.git
    git push -u origin main
    ```

Step 3: Get Zenodo DOI (optional but recommended)
  1. Go to zenodo.org
  2. Link your GitHub account
  3. Enable the repository
  4. Create a release on GitHub (v1.0)
  5. Zenodo automatically creates permanent DOI
  6. Add DOI badge to your README
