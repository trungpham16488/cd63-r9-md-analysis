SIMULATION METHODS AND COMMANDS
================================================================================

Molecular dynamics simulations were performed using GROMACS 2023.4 (https://www.gromacs.org/). System preparation utilized CHARMM-GUI (https://www.charmm-gui.org/). ================================================================================
GROMACS COMMANDS USED (for Supplementary Methods)
================================================================================

System preparation (CHARMM-GUI):
1. Protein structure preparation (CD63/CD9 with R9 conjugated via EDC/NHS)
2. Solvation in TIP3P water box (1.2 nm minimum distance)
3. Ion addition (0.15 M NaCl for neutralization and physiological conditions)

Energy minimization:
gmx grompp -f em.mdp -c system.gro -p topol.top -o em.tpr
gmx mdrun -v -deffnm em

NVT equilibration (300 K):
gmx grompp -f nvt.mdp -c em.gro -r em.gro -p topol.top -o nvt.tpr
gmx mdrun -v -deffnm nvt

NPT equilibration (1 bar):
gmx grompp -f npt.mdp -c nvt.gro -r nvt.gro -p topol.top -o npt.tpr
gmx mdrun -v -deffnm npt

Production MD:
gmx grompp -f production.mdp -c npt.gro -p topol.top -o production.tpr
gmx mdrun -v -deffnm production

Trajectory processing:
# Remove periodic boundary artifacts
gmx trjconv -s production.tpr -f production.xtc -o production_noPBC.xtc -pbc mol -ur compact

# Extract production trajectory (1.38-4.5 ns)
gmx trjconv -s production.tpr -f production_noPBC.xtc -o production_1380to4500ps.xtc -b 1380 -e 4500

Analysis commands:
# Backbone RMSD
gmx rms -s production.tpr -f production_1380to4500ps.xtc -n index.ndx -o rmsd_backbone.xvg -tu ns
# Selected groups: Backbone (for fit and analysis)

# Per-residue RMSF
gmx rmsf -s production.tpr -f production_1380to4500ps.xtc -n index.ndx -o rmsf_residue.xvg -res
# Selected group: Protein_noR9

# R9 radius of gyration
gmx gyrate -s production.tpr -f production_1380to4500ps.xtc -n index.ndx -o gyrate_r9.xvg
# Selected group: R9_peptide

# Hydrogen bonds
gmx hbond -s production.tpr -f production_1380to4500ps.xtc -n index.ndx -num hbond.xvg
# Selected groups: Protein_noR9 and R9_peptide
# Default criteria: distance cutoff 0.35 nm, angle cutoff 30°

tcoupl                  = V-rescale
tau_t                   = 0.1
pressure                = 1.0        ; bar
pcoupl                  = Parrinello-Rahman
tau_p                   = 2.0

rcoulomb                = 1.2
rvdw                    = 1.2
pbc                     = xyz

MD SIMULATION AND ANALYSIS CODE
Advanced Functional Materials submission: "Computationally Engineered Peptide-Exosome Nanocarriers for Continuous Bioelectronic Monitoring of 3D Epidermal Regeneration"

CONTENTS:
1. analysis_scripts/ - Python scripts for figure generation
2. gromacs_commands/ - Complete GROMACS workflow and analysis
3. starting_structures/ - Initial system coordinates

REQUIREMENTS:
- GROMACS 2023.4 or later (https://www.gromacs.org/)
- Python 3.x with NumPy, Pandas, Matplotlib, openpyxl

USAGE:
1. Review gromacs_commands/run_simulation.sh for complete MD workflow
2. Use analysis_commands.sh for trajectory analysis
3. Run Python scripts in analysis_scripts/ to generate figures

SIMULATION DETAILS:
- Force field: CHARMM36m
- Water model: TIP3P
- Salt concentration: 0.15 M NaCl
- Temperature: 300 K
- Pressure: 1 bar
- Equilibration: 1.38 ns (NVT + NPT)
- Production: 3.12 ns (1.38-4.5 ns total)

ANALYSIS:
- RMSD: Backbone alignment and calculation
- RMSF: Per-residue flexibility
- Gyration: R9 peptide compactness
- H-bonds: Protein-R9 interactions (distance < 0.35 nm, angle < 30°)
